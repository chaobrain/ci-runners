# ci-runners

Shared self-hosted GitHub Actions runners for chaobrain projects: host setup, the
executor, the pre-job hook, and the actions and reusable workflows that projects call.

- [docs/design.md](docs/design.md): the contract (approved 2026-11-05)
- [docs/consumers.md](docs/consumers.md): how a project onboards
- [AGENTS.md](AGENTS.md): how this repository is worked on

No host inventory lives in this repository; it stays on the hosts.
